# 권오진 정책자금·경영자문 사이트

권오진 대표의 기존 공개 사이트를 기반으로 구성한 2차 개발 소스입니다.

## 유지되는 핵심 기능

- 기존 홈 디자인과 대표 사진
- 정책자금·경영자문 소개
- 상담 신청, 전화, 이메일, 카카오톡 연결
- 경력, 언론 활동, 저서 소개

## 경영 인사이트 발행

모든 글은 `app/insights/content.ts` 한 곳에서 관리합니다. 같은 형식으로 새 글을 추가하면 다음 항목이 함께 반영됩니다.

- 홈페이지 경영 인사이트 목록
- 글마다 독립된 주소
- `sitemap.xml`
- `rss.xml`과 호환용 `feed.xml`
- 네이버 블로그용 글과 SNS용 짧은 홍보문

홍보문 생성:

```bash
npm run content:generate
```

생성 결과는 `content-packs` 폴더에서 확인할 수 있습니다.

## 확인 명령

```bash
npm install
npm run build
```

현재 ChatGPT Sites 공개 주소와 네이버 서치어드바이저 설정은 이 저장소만으로 변경되지 않습니다.
